Dashboard Wisata Lampung

An interactive dashboard project for exploring tourism data in Lampung, built as a practical project in data processing and visualization.

Project overview

The project presents tourism data in a more interactive form so users can explore information through a web dashboard instead of reading raw data only. The repository uses Python and Pandas for data processing and Streamlit for the dashboard interface.
